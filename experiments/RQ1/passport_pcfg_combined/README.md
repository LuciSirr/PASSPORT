# PASSPORT + PCFG Combined Wordlists

Wordlists for the PASSPORT+PCFG curve in Figure 3 / RQ1.

For each profile, the list alternates PASSPORT enhanced and PCFG candidates to realize a 50/50 distinct budget split. Once the profile-specific PASSPORT list is exhausted, remaining lines are filled from the language PCFG list. Use the first n lines of each file for budget n.

Maximum materialized budgets: English 1,000,000; German 500,000; Czech 50,000.
